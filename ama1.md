## Which command is used to unstage changes and move them back from the staging area?
git restore --staged <file> is used to unstage changes and move them back to the working directory.

## What is the full form of PEP 8?
PEP 8 stands for Python Enhancement Proposal 8.

## What is the difference between DBMS and RDBMS?
DBMS manages databases generally, while RDBMS stores data in related tables using relationships.

## Which SQL command is used to create a user?
CREATE USER username WITH PASSWORD 'password';

## What is the use of aggregate functions in SQL?
Aggregate functions perform calculations on multiple rows and return a single result, such as COUNT(), SUM(), AVG(), MIN(), and MAX().


## Which query is used to check the databases and their owners?
\l or \list in PostgreSQL is used to check databases and their owners.


## How can you run an SQL query from the terminal?
Use psql -d database_name -c "SELECT ...;" to run an SQL query from the terminal.

## How can you change the ownership of a file?
chown user:group filename is used to change the ownership of a file.

## What is the use of LIMIT in SQL?
LIMIT restricts the number of rows returned by an SQL query.

## What is the GROUP BY clause?
GROUP BY groups rows with the same values so aggregate functions can be applied to each group.

## What do you understand by DDL?
DDL stands for Data Definition Language and includes commands such as CREATE, ALTER, DROP, and TRUNCATE

## How can you retrieve distinct values from a particular column?
SELECT DISTINCT column_name FROM table_name; retrieves unique values from a column.

## What is the difference between SQL and MySQL?
SQL is a query language/standard, while MySQL is a relational database management system that implements SQL.

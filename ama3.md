## What are some string methods in JavaScript?

- Common string methods are toUpperCase(), toLowerCase(), includes(), indexOf(), slice(), substring(), replace(), trim(), split(), and concat().

## Give an example of a higher-order function.

- A higher-order function is a function that takes another function as an argument or returns a function; for example, map() takes a callback function.

## What is interpolation in JavaScript?

- Interpolation means inserting variables or expressions inside a string using template literals, for example, `Hello ${name}`.

## What are the different types of scope in JavaScript?

- JavaScript mainly has global scope, function scope, block scope, and module scope.

## What is the difference between Promise.all() and Promise.allSettled()?

- Promise.all() rejects as soon as one promise fails, while Promise.allSettled() waits for all promises to finish and returns the status of each promise.

## What are the different types of joins in SQL?

- The main SQL joins are INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, CROSS JOIN, and SELF JOIN.

## What is the difference between indexOf() and findIndex()?

- indexOf() searches for a specific value, while findIndex() searches for the index of the first element that satisfies a given condition.

## What is the difference between Object.entries() and Object.fromEntries()?

- Object.entries() converts an object into an array of key-value pairs, while Object.fromEntries() converts key-value pairs back into an object.

## What is asynchronous programming?

- Asynchronous programming allows JavaScript to perform time-consuming tasks without blocking the execution of other code.

## What is promise chaining?

- Promise chaining means using multiple .then() calls one after another to perform asynchronous operations in a specific sequence.

## Who created JavaScript?

- JavaScript was created by Brendan Eich in 1995 while he was working at Netscape.

## What is hoisting?

- Hoisting is JavaScript's behavior of processing declarations before executing the code, which allows some variables and functions to be accessed before their declaration.

# What is an API?

An API (Application Programming Interface) allows two software applications to communicate with each other. For example, a weather application can use a weather API to get the current temperature of a city.
# What is session middleware?

Session middleware helps a web application maintain information about a user across multiple requests. For example, after logging in, a user can navigate between pages without having to log in again on every page. In Django, session middleware makes session data available through request.session.
# What is AJAX?

AJAX stands for Asynchronous JavaScript and XML. It allows a webpage to send and receive data from a server without reloading the entire page. For example, a search box can show suggestions while we type.
# What is the difference between SQLite and PostgreSQL?

SQLite is a lightweight database that stores data in a file and is easy to set up. PostgreSQL is a more powerful database server designed to handle complex queries, multiple users, and larger applications. SQLite is useful for small projects and testing, while PostgreSQL is often used for production applications.
# What is z-index in CSS?

z-index controls the stacking order of overlapping elements. An element with a higher z-index generally appears in front of an element with a lower value, provided their stacking contexts allow it. For example, it can help display a dropdown menu above other content.

# What is the difference between querySelector() and querySelectorAll()?

querySelector() returns the first element that matches a CSS selector. querySelectorAll() returns all matching elements in a static NodeList.
For example, document.querySelector('.item') selects the first element with the class item, while document.querySelectorAll('.item') selects all matching elements.
# What is the Django framework?

Django is a Python web framework used to build web applications quickly and securely. It provides features such as URL routing, models, templates, forms, authentication, and an ORM for working with databases. It follows the Model-View-Template (MVT) architectural pattern.

 # What is O in SOLID?
- O stands for Open/Closed Principle.
- A class should be open for extension but closed for modification.

# What is the arguments object in JavaScript?
- arguments is a special array-like object available inside a regular JavaScript function. It contains all arguments passed to that function.

# What is the flow of Django with Python?
- A Django request comes from the browser, passes through middleware and URL routing, reaches a view, where the application logic and database operations happen. The view can render a template and Django sends the resulting response back to the browser.

# Why do we need migrations in Django?
- Migrations are used to track and apply database schema changes based on changes in Django models.

# What is CSRF?
- CSRF = Cross-Site Request Forgery.
- It is an attack where a malicious website tries to make a user's browser send an unwanted request to another website where the user is already logged in.

# What are Django signals?
- Django signals allow different parts of a Django application to communicate when a particular event occurs.

# What is manage.py?
- manage.py is a command-line utility provided by Django for managing a project.

# Difference between WSGI and ASGI
- Both are interfaces between a Python web application and a web server.
- WSGI = Web Server Gateway Interface.
- ASGI = Asynchronous Server Gateway Interface.

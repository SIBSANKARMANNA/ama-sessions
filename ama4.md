## What is the mv command?

mv is a Linux command used to move or rename files and directories.

## What is the meaning of O in SOLID?

O stands for Open/Closed Principle.
we should be able to add new functionality without changing existing, working code.

## What is a function?

A function is a reusable block of code designed to perform a specific task.

## How do you create a class?

In JavaScript, we use the class keyword to create class.

## What is S in SOLID?

S = Single Responsibility Principle
a User class should handle user-related operations, while a separate UserReport class should handle report generation.

## What are the bitwise operators?

Bitwise operators work directly with the binary bits of numbers.

## What is the difference between bitwise AND and OR?

Bitwise AND (&) returns 1 only when both bits are 1.
Bitwise OR (|) returns 1 when at least one bit is 1.

## Why do we use the script tag at the end of the body?

We commonly place the JavaScript script tag at the end of body so that the HTML elements are loaded first.

## How do you get the last 30 lines of a file in CLI?

tail -n 30 filename.txt

## What are setInterval() and setTimeout()?

Both are JavaScript functions used to execute code after a period of time.

setTimeout() executes a function once after the specified delay.
setInterval() executes a function repeatedly after every specified interval.

## When we design a function, why do we need return?

return is used to send a result back from a function.So it is possible to manipulate the return value.

## What is the difference between catch and throw?

throw is used to create/raise an error.
catch is used to handle an error.

## What is the difference between the callback queue and microtask queue?

Both are queues used by the JavaScript event loop, but microtasks have higher priority.

# Explain /compact, /clear, and /context.

These are slash commands used to manage the conversation and context in Claude Code.
/compact — Summarizes the conversation to reduce the amount of context being used while preserving important information for continuing the work.
/clear — Clears the current conversation context so you can start a fresh task.
/context — Shows information about the context window and how context is being used, helping you understand what is consuming space.
# What are connectors?

Connectors allow an AI application to connect to external services and access their data or functionality. For example, a connector might allow an AI assistant to search files in Google Drive or retrieve information from another connected service.
# What is the difference between an agent and a subagent?

An agent is an AI system that works toward a goal using instructions, tools, and sometimes multiple steps. A subagent is a separate, more focused agent that can be assigned a smaller task by a main agent.
# What are hooks?

Hooks are commands or scripts that run automatically when specific events occur. In Claude Code, hooks can be used to run formatting, perform checks, or enforce certain rules before or after actions. For example, a hook could run a linter after a file is modified.
# What is a codebase?

A codebase is the collection of source code and related files that make up a software project. It can include application code, tests, configuration files, documentation, and other resources. When Claude Code examines a codebase, it can use the existing project structure and code to understand where changes should be made.
# What does MCP do?

MCP stands for Model Context Protocol. It is a standard that allows AI applications to connect to external tools and data sources through a common interface.
